# Política de segurança

## Como relatar uma vulnerabilidade

Use o recurso **Report a vulnerability** na aba **Security** deste repositório para enviar um relato privado. Não publique detalhes de uma vulnerabilidade ainda não corrigida em uma issue ou discussão pública.

Inclua, se possível:

- uma descrição do problema e seu impacto;
- os passos para reproduzi-lo;
- a versão ou o commit afetado;
- evidências ou um exemplo mínimo, sem incluir dados pessoais ou segredos.

A equipe do projeto analisará o relato e poderá pedir informações adicionais pelo canal privado do GitHub. Não há prazo formal de resposta ou garantia de correção; faremos o possível para confirmar o recebimento e comunicar o andamento.

## Escopo e versões

A política cobre o código e os arquivos mantidos neste repositório. Como o projeto é mantido pela comunidade e pode mudar rapidamente, não há versões com suporte de longo prazo. Informe a versão ou o commit usado no relato.

## Security policy (English)

Use **Report a vulnerability** on this repository's **Security** tab to submit a private report. Please do not disclose details of an unpatched vulnerability in a public issue or discussion.

When possible, include the impact, reproduction steps, affected version or commit, and a minimal proof of concept. Do not include personal data or secrets.

Reports are reviewed through GitHub's private channel. There is no formal response time or guarantee of a fix; we will make a reasonable effort to acknowledge the report and share its status.

This policy covers code and files maintained in this repository. The project has no long-term supported release versions; include the version or commit you used.
